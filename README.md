# Elmina: Coast, Castle, Memory

The published website for a browser-based AR exhibition piece. Visitors open it
from a QR code, explore a 3D model of Elmina Castle, and place it in their own
space on a phone or tablet.

**The model is an interpretive reconstruction based on authorised reference
material. It is not a surveyed digital twin.** Sources and acknowledgements are
listed on the page.

This repository holds only the built site (static files). It is generated from
a separate source project; do not edit these files by hand.

- No analytics, accounts, cookies or data collection.
- AR placement lasts only for the visitor's current session.
